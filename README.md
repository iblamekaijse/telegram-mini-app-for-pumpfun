# telegram-mini-app-for-pumpfun

Локальная браузерная панель одного виртуального правила. Есть отдельные режимы: синтетический DEMO и реальные снимки DEX Screener для индексируемых пар PumpSwap токен/WSOL. Поддерживаются виртуальные позиции и подключаемый обычный Telegram-бот одного владельца. Кошельков и реальных сделок нет; веб-панель остаётся доверенной локальной. Формат распространения продукта этим прототипом не утверждается.

Для воспроизводимого запуска используйте Node.js **24.19.0** (ветка 24 LTS). Зависимости устанавливать не требуется. Для Windows приведён один способ через WSL 2 / Ubuntu в [инструкции передачи](HANDOFF.md#windows).

```sh
cd prototypes/rule-lifecycle
npm start
```

На том же компьютере откройте **http://127.0.0.1:4173**. Это локальный адрес, а не ссылка для открытия Cloud-задачи с телефона. Создайте правило, включите его и передайте цену через DEMO-пульт. Состояние сохраняется в SQLite после обновления страницы и перезапуска сервера.
