# telegram-mini-app-for-pumpfun — v0.1.0-paper.1

Первый целостный **локальный виртуальный выпуск**. Готовый код находится в **main**, проверяемая версия — Git-тег **v0.1.0-paper.1**. Node.js **24.19.0**, SQLite **v7**, только стандартные модули Node; npm install и публикация npm-пакета не нужны.

Один владелец управляет виртуальными правилами/позициями в обычном Telegram-чате: создание → подтверждение → отдельное включение или окончательный отзыв до входа → уведомления → TP/SL или запрос закрытия → сохранённый результат и история. Локальная панель служит для первоначальной привязки, настройки и тех же операций. Есть команды setup, doctor, backup и restore.

Источники: синтетический DEMO и HTTP-снимки **DEX Screener** для индексируемых **PumpSwap токен/WSOL** на Solana; условие использует **priceUsd (USD/токен)**. Bonding curve Pump.fun, другие площадки/источники и гарантированная полнота/свежесть данных агрегатора не поддерживаются. Виртуальная модель не включает исполнение сделок, комиссии и проскальзывание. Нет кошельков, подписей, реальных средств/сделок, Mini App или публичного сервера. Unknown, закрепление пула и однократность операций сохраняются.

По предоставленному пользователем скриншоту WSL подтверждены Node.js 24.19.0, успешный getMe настоящего бота, совпадение ID, отсутствие webhook, сохранение настроек и запуск сервера. Это **не** подтверждает полный живой Telegram-цикл. Автоматические проверки используют временные данные и тестовые транспорты; реальные сообщения получателям не отправляются.
