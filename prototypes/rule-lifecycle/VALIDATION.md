# Проверки перед передачей

Среда: Linux, Node.js **v24.19.0**, npm **11.9.0**. Приложение не требует внешних npm-зависимостей.

```bash
cd prototypes/rule-lifecycle
npm test
```

Итог сохранённого полного набора: **125 passed, 0 failed, 0 skipped**. [TAP-отчёт](results/web-tests.tap). Он включает ядро, сохранение/восстановление отдельными процессами, синтетический источник, решения владельца и 6 HTTP-интеграционных проверок прежней панели, а также 13 новых проверок рыночных наблюдений. Проверяются повторы/конкуренция, сроки, атомарные решения/курсоры, unknown, потеря истории, SIGKILL в существенных точках, запрет повторного исполнения и отказ при непригодном хранилище.

Прежние наборы 26 / 59 / 81 / 106 проверок были промежуточными состояниями того же развивавшегося прототипа. Их исходники сохранены в текущем наборе; старые текстовые выводы и CLI-журналы остаются в исходной Cloud-среде, в поставку не включены.

Интерфейс фактически проверен Chromium через Python Playwright в этой Linux-среде. [Структурированный отчёт](results/web-browser.json) и снимки [пустой формы](results/web-empty.png), [компьютера](results/web-desktop.png), [узкого экрана](results/web-mobile.png) сохранены из работающего приложения. Браузерная проверка проходит создание/валидацию, обе цены, успех, обновление страницы, SIGKILL/перезапуск сервера, независимость unknown от проверки потока, отключённый accept_gap, отзыв и неудачу. Ошибок JavaScript нет; на проверенных размерах нет горизонтального переполнения. Снимки просмотрены визуально.

Повторить браузерную проверку можно командой `python3 web/browser-check.py`, но только при отдельно установленном Python Playwright и Chromium. Это инструмент проверки, не зависимость запуска приложения.

Cloud-preview, установка/запуск на Windows/WSL конкретного пользователя и доступ из его браузера здесь не проверены. Синтетические проверки не подтверждают интеграцию с Solana, onchain-ограничения или безопасность реальных средств. Старые эксперименты не запускались. На текущем этапе ядро расширено отдельным типом рыночного наблюдения; прежние синтетические сценарии сохранены.


## Рыночный режим — отдельные доказательства

- **LIVE:** [market-live-browser.json](results/market-live-browser.json). Chromium и фактический публичный API: mint → пул/пара/USD → правило → следующий автоматический снимок → виртуальное условие → reload → SIGKILL и новый процесс сервера с той же единственной операцией. Ключ/тариф не использовались. [Компьютер](results/market-live-desktop.png), [телефон](results/market-live-mobile.png).
- **OFFLINE:** [market-fixture-browser.json](results/market-fixture-browser.json). Явно изменяемые копии сохранённого ответа: ошибка → старый снимок не даёт сигнал → устаревание → восстановление с новым наблюдением → виртуальный результат; затем неподдерживаемый mint/no_data. [Компьютер](results/market-fixture-desktop.png), [телефон](results/market-fixture-mobile.png). Эти сценарии не выдаются за живые сбои провайдера.
- **OFFLINE npm test:** market.test.mjs использует [публичные поля сохранённого ответа](fixtures/dexscreener-pumpswap.json) с [provenance и SHA-256](fixtures/dexscreener-provenance.json). Подтверждены точность/единицы, идентификация и привязка, ограничения опроса/429, отказ подмены, отсутствие сигнала на старой цене, одно виртуальное намерение, сохранение результатов/unknown и отмена prepared до нового явного включения. Старые 112 проверок не удалены.
- **Сохранённый DEMO:** прежний web/browser-check.py повторно пройден с новым интерфейсом; отчёт web-browser.json и его снимки обновлены.

Поддержка PumpSwap основана на ярлыках и данных DEX Screener, а не на локальном исполнении финансовых программ или onchain-верификации пула. Снимки не доказывают полноту потока, возраст цены у агрегатора, выгодность/достижимость цены или реальную покупку. Не проверены bonding curve Pump.fun, другие DEX, реальный поток Solana, Windows пользователя и внешний Cloud-preview. [Контракт и запуск](web/MARKET_DATA.md).
