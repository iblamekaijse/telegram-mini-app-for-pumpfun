# Проверки перед передачей

Среда: Linux, Node.js **v24.19.0**, npm **11.9.0**. Приложение не требует внешних npm-зависимостей.

```bash
cd prototypes/rule-lifecycle
npm test
```

Итог сохранённого полного набора: **112 passed, 0 failed, 0 skipped**. [TAP-отчёт](results/web-tests.tap). Он включает ядро, сохранение/восстановление отдельными процессами, синтетический источник, решения владельца и 6 HTTP-интеграционных проверок. Проверяются повторы/конкуренция, сроки, атомарные решения/курсоры, unknown, потеря истории, SIGKILL в существенных точках, запрет повторного исполнения и отказ при непригодном хранилище.

Прежние наборы 26 / 59 / 81 / 106 проверок были промежуточными состояниями того же развивавшегося прототипа. Их исходники сохранены в текущем наборе; старые текстовые выводы и CLI-журналы остаются в исходной Cloud-среде, в поставку не включены.

Интерфейс фактически проверен Chromium через Python Playwright в этой Linux-среде. [Структурированный отчёт](results/web-browser.json) и снимки [пустой формы](results/web-empty.png), [компьютера](results/web-desktop.png), [узкого экрана](results/web-mobile.png) сохранены из работающего приложения. Браузерная проверка проходит создание/валидацию, обе цены, успех, обновление страницы, SIGKILL/перезапуск сервера, независимость unknown от проверки потока, отключённый accept_gap, отзыв и неудачу. Ошибок JavaScript нет; на проверенных размерах нет горизонтального переполнения. Снимки просмотрены визуально.

Повторить браузерную проверку можно командой `python3 web/browser-check.py`, но только при отдельно установленном Python Playwright и Chromium. Это инструмент проверки, не зависимость запуска приложения.

Cloud-preview, установка/запуск на Windows/WSL конкретного пользователя и доступ из его браузера здесь не проверены. Синтетические проверки не подтверждают интеграцию с Solana, onchain-ограничения или безопасность реальных средств. Старые эксперименты не запускались. Код торговой логики и серверного исполнения при подготовке передачи не изменён.
